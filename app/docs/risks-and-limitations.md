# Risks and Limitations (TRL-4)

## Connectivity and upstream dependency
External sources can be slow or fail. Pollers must degrade gracefully.

## Data freshness
Decision outputs must expose freshness and allow UNKNOWN/HOLD outputs.

## Security posture
TRL-4 system is not yet hardened; do not represent it as production-ready.

## Accuracy and liability
Outputs are advisory. Final operational authority remains with the operator.
